==================================================================
  Part 1/5: KMS 信封加密 — 密钥全生命周期
==================================================================
  ▶ 创建 AES-256-GCM 密钥 demo-aes
  ▶ 加密敏感数据
      密文(前32): AAAAAaluSvtw+HqovC4H7THAzka4uvXi...  版本化自路由格式 [ver|nonce|ct]
  ▶ 解密回原文
      plaintext: 身份证 110101199001011234
  ▶ 轮转密钥 → v2（旧密文仍可解密，版本自动路由）
  ▶ 用 v2 解 v1 密文
      仍得到: 身份证 110101199001011234
  ▶ GenerateDataKey
      明文 DEK 经 SecureBuffer 受控暴露，写响应后立即 Wipe
  ▶ RSA-4096-PSS 签名验签
      valid: True
  ▶ HMAC 盲索引
      加密字段也能等值查询（HMAC 做索引列，不可逆）

==================================================================
  Part 2/5: PKI — 自建 CA 签发 X.509 证书
==================================================================
  ▶ 创建自签根 CA (RSA-4096)
      serial: 241229132243097696184747...
      PEM: -----BEGIN CERTIFICATE-----
  ▶ 签发服务器证书 demo-service
      serial: 651142433940386923077508...  TTL: 365d
  ▶ 验证证书链
      valid: True  revoked: False

==================================================================
  Part 3/5: OCSP — 证书吊销 + 在线状态查询 (RFC 6960)
==================================================================
  ▶ 吊销 demo-service 证书
      reason: keyCompromise
  ▶ 获取 CRL
      CRL DER: 724 bytes（含已吊销序列号）
  ▶ 吊销后再次验证
      valid: False  revoked: True

==================================================================
  Part 4/5: SDF 软件密码机 — GM/T 0018-2023 国密设备接口
==================================================================
  ▶ SDF 设备信息
      Yvonne Software SDF Device  GM/T 0018-2023
  ▶ SM2 密钥对生成
      pub: 040d86a00ed4ea14f303a19bd9931fd221f2a631...
  ▶ SM2 签名验签 (SM2WithSM3)
      valid: True
  ▶ SM3 哈希
      SM3('abc') = 66c7f0f462eeedd9d1f2d46bdc10e4e2...
  ▶ SM4 加解密往返
      plaintext: SM4 secret

==================================================================
  Part 5/5: 审计 — 哈希链完整性
==================================================================
  ▶ 审计链（dev 模式说明）
      dev 模式审计实时输出到服务 stdout（JSON 行），含 HMAC 链 prev_hash。
      上方演示的所有操作（CreateKey/Encrypt/Sign/CreateCA/Issue/Revoke/SDF）
      均已逐条记录。cluster 模式落盘 + Syslog 双写，可用 /api/v1/audit/query 检索。
