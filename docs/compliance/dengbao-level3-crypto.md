## 2. 网络与通信（9/10 完全合规，1 部分合规）

### 2.1 网络架构

#### 控制点 N-2.1.1：网络划分与隔离

- **等保要求**：采用密码技术实现网络访问控制
- **Yvonne 实现**：
  - KMS 端口 8200（应用层）、8250（Admin 层）双向隔离
  - 国密 IPSec VPN 支持（GM/T 0022）：`internal/network/ipsec_gmsm.go`
- **结论**：✅ **完全合规**

### 2.2 通信保密性

#### 控制点 N-2.2.1：敏感字段加密传输

- **要求**：使用 SM4 / AES 加密通信信道
- **Yvonne 实现**：
  - TLS 1.3（默认）：`internal/api/server.go:88-114`
  - 国密 TLS（`gmsm` tag）：`ECC_SM4_GCM_SM3`、`ECDHE_SM4_GCM_SM3`
- **证据**：`scripts/security-check.sh` 第 5 项检查 cipher suite
- **结论**：✅ **完全合规**

#### 控制点 N-2.2.2：通信前双向身份鉴别

- **要求**：建立连接前采用密码技术验证对方身份
- **Yvonne 实现**：
  - mTLS（`internal/api/mtls.go`）：v1.4.0 客户端证书认证
  - Bearer Token 二次认证
- **结论**：✅ **完全合规**

### 2.3 通信完整性

#### 控制点 N-2.3.1：完整性校验

- **要求**：使用 HMAC 算法验证网络数据完整性
- **Yvonne 实现**：
  - TLS GCM 模式内置完整性（AEAD）
  - HMAC-SHA256 / HMAC-SM3（国密模式）
- **结论**：✅ **完全合规**

#### 控制点 N-2.3.2：抗重放保护

- **要求**：防止网络数据重放攻击
- **Yvonne 实现**：
  - TLS 1.3 内置 sequence number
  - API 层 nonce + timestamp 单调递增
  - JWT `exp` 过期时间
- **结论**：✅ **完全合规**

### 2.4 通信抗抵赖

#### 控制点 N-2.4.1：通信操作抗抵赖

- **要求**：关键操作可追溯不可抵赖
- **Yvonne 实现**：
  - 所有写操作要求认证（Bearer Token 或 mTLS Client Cert）
  - 审计日志包含 user/actor/trace_id
- **结论**：✅ **完全合规**

### 2.5 网络访问控制

#### 控制点 N-2.5.1：网络边界访问控制

- **要求**：边界使用密码模块认证
- **Yvonne 实现**：
  - 防火墙规则：`docs/deploy/yvonne-firewall.md`
  - 集群节点间 mTLS：`internal/cluster/mtls.go`（v1.4.0 节点间双向认证）
- **结论**：✅ **完全合规**

### 2.6 抗 DDoS 与入侵

#### 控制点 N-2.6.1：抗 DDoS

- **要求**：具备流量清洗能力
- **Yvonne 实现**：通过对接云抗 DDoS 服务（部署层）
- **结论**：✅ **完全合规**

### 2.7 网络协议合规

#### 控制点 N-2.7.1：禁用不安全协议

- **要求**：禁用 SSLv3、TLS 1.0、TLS 1.1
- **Yvonne 实现**：`MinVersion: tls.VersionTLS12`（默认 TLS 1.3）
- **结论**：✅ **完全合规**

#### 控制点 N-2.7.2：密码模块合规（部分合规）

- **要求**：使用国家密码管理局认证的密码模块
- **Yvonne 实现**：

  - **国密软件**：tjfoc/gmsm v1.4.1（待国密认证）
  - **国际软件**：`crypto/tls` 标准库
- **当前状态**：**部分合规**（国产 HSM 软件认证状态依赖国密局公告）
- **结论**：⚠️ **部分合规**（v1.4.1 引入国产密码机对接认证清单）
